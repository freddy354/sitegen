A faster drop-in for makefun-site 1.0.0, for the make.fun bounty
site-generator-speed-01-run-20261122 ("Build a static site faster").

`solve.js` reimplements makefun-site's build with byte-identical output,
optimised for CPU time; `main.ts` is the harness driver (the house
baseline's, unchanged). See `BUILD_REPORT.md` for the design, the practice
results and the timing comparison against the baseline.
